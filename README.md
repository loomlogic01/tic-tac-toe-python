# Tic-Tac-Toe Game using Python 

A classic Tic-Tac-Toe game built with Python and Tkinter.

## About the Project

This project lets two players play Tic-Tac-Toe through a graphical user interface. Players take turns marking the board, and the game checks for winning combinations and draws.

## Features

- Graphical interface using Tkinter
- Two-player gameplay
- Winner detection
- Winning combination highlighting
- Draw detection
- Restart game option

## Technologies Used

- Python 3
- Tkinter

## How to Run

1. Install Python 3.
2. Clone this repository:

   ```bash
   git clone https://github.com/loomlogic01/tic-tac-toe-python.git
   ```

3. Open the project folder.
4. Run:

   ```bash
   python tic_tac_toe_game_in_python.py
   ```
